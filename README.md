# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user inputs for principal, rate of interest, and time period.

## Description
This project is part of the Getting Started with Git and GitHub final assignment. It features a lightweight calculator written in Bash to compute financial interest over a specified duration.

## Usage
To run the script locally in your terminal, execute the following commands:
```bash
chmod +x simple-interest.sh
./simple-interest.sh

Input FieldsPrincipal: The initial amount of money invested or borrowed.Rate of Interest: The annual percentage rate.Time Period: The duration in years.FormulaThe script computes simple interest using the standard formula:$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$Where:$P$ = Principal amount$T$ = Time period in years$R$ = Annual interest rate
